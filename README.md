# 📊 Sales Data Analysis System

A Python-based sales data analysis system that 
demonstrates data science techniques using 
Pandas and Matplotlib libraries.

## 🎯 Project Overview

This project analyzes sales data to:
- Calculate total and average sales
- Identify best and worst selling products
- Generate professional bar chart visualizations

## 📁 Two Versions Available

### Version 1: Basic Program
- Uses hardcoded sales data
- Good for learning fundamentals
- Always shows same results

### Version 2: Interactive Program
- Accepts user input
- Can analyze any products
- More practical for real world use

## 🛠️ Technologies Used

- Python 3.14.3
- Pandas - Data manipulation
- Matplotlib - Data visualization

## 🚀 How to Run

### Install required libraries:
pip install pandas matplotlib

### Run Basic Version:
python sales_analysis.py

### Run Interactive Version:
python interactive_sales_analysis.py
