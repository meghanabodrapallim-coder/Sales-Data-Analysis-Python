1. PROJECT OVERVIEW
=====================================================

This project analyzes sales data of 5 products using Python.
It calculates total sales, average sales, identifies the 
best-selling product, and displays a bar graph.

=====================================================
2. TECHNOLOGIES USED
=====================================================

- Python 3.14.3
- Pandas library (for data analysis)
- Matplotlib library (for visualization)

=====================================================
3. HOW THE PROGRAM WORKS
=====================================================

Step 1: Creates sample sales data for 5 products
Step 2: Stores data in a Pandas DataFrame
Step 3: Calculates total sales (sum of all sales)
Step 4: Calculates average sales (mean)
Step 5: Finds the best-selling product (maximum sales)
Step 6: Creates a bar chart to visualize the data
